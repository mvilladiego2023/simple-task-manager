# Simple Task Manager

Simple Task Manager is a web application that allows users to create and manage tasks. Users can add tasks, view existing tasks, edit task information, mark tasks as completed, and delete tasks.

## Features

- Add new tasks
- View saved tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Store task information in a Back4App database

## Technologies Used

- HTML
- CSS
- JavaScript
- Back4App
- Parse JavaScript SDK
- GitHub
- Netlify
- ChatGPT for AI-assisted development

## How to Use the Application

1. Open the deployed application.
2. Enter a task title.
3. Enter a description if needed.
4. Select a due date.
5. Click **Add Task**.
6. Use **Edit** to modify a task.
7. Use **Complete** to mark a task as completed.
8. Use **Delete** to remove a task.

## Project Setup

To run the project locally:

1. Clone or download this GitHub repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The application connects to Back4App using the Parse JavaScript SDK.

## Database

The application uses Back4App to store task information.

The `Task` database class contains:

- `title`
- `description`
- `dueDate`
- `status`
